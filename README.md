# 📖 Overview

**DarkWatch AI** is an enterprise-grade AI-powered Cyber Defense Platform that enables organizations to proactively monitor, detect, analyze, and respond to cyber threats in real time.

Designed for Security Operations Centers (SOC), DarkWatch AI combines Machine Learning, Behavioral Analytics, Threat Intelligence, and Large Language Models to transform millions of security events into actionable intelligence.

Unlike traditional SIEM platforms that rely on static rules, DarkWatch AI continuously learns from user behavior, network traffic, and system logs to identify suspicious activities before they escalate into security incidents.

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/DarkWatchAI.git
```

---

## Install Frontend

```bash
cd client
npm install
npm run dev
```

---

## Install Backend

```bash
cd server
npm install
npm run dev
```

---

## AI Service

```bash
cd ai-service

pip install -r requirements.txt

uvicorn main:app --reload
```
